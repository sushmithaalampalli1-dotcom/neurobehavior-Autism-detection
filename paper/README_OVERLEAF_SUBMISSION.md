# NeuroBehavior-ASD: IEEE Paper Publication & Overleaf Submission Package

This folder contains the complete, camera-ready **IEEE Conference / Journal Manuscript** for the **NeuroBehavior-ASD** research project:

* **Paper Title:** *NeuroBehavior-ASD: Deep Learning-Based Autism Detection Using Brain Imaging Biomarkers and Behavioral Features with a Personalized Support System*
* **Target Template:** IEEE Conference 2-Column Standard (`IEEEtran.cls`)
* **Key Results Reported:**
  * **95.21% Test Accuracy** and **0.9814 ROC-AUC** on 334 untouched ABIDE I/II test cohort subjects
  * **100% Test Accuracy** and **1.00 ROC-AUC** on Pediatric 2-Months axial scan cohort
  * Indian Autism Screening Questionnaire (IASQ; PMC8062015 validated)
  * Geospatial proximity navigation to accredited support hospitals across India

## 🚀 How to Publish / Compile on Overleaf (1-Click)

1. **Log in to Overleaf:** Go to [overleaf.com](https://www.overleaf.com).
2. Click **New Project** ➔ **Upload Project**.
3. Select the `NeuroBehavior_ASD_IEEE_Paper_Overleaf_Package.zip` file (or upload `main.tex` and `pipeline_architecture.png` together).
4. In Overleaf project settings:
   * **Compiler:** `pdfLaTeX` (default)
   * **Main Document:** `main.tex`
5. Click **Recompile** (Ctrl+Enter / Cmd+Enter).
6. Overleaf will generate the final, publication-grade 2-column IEEE PDF with full equations, tables, figures, and IEEE-formatted citations.
7. Click **Download PDF** to obtain your publication-ready document for conference or journal submission.
